# Personal Resume Website

A simple, clean, and professional **resume webpage** built using HTML and CSS. This project presents my education, technical skills, internship experience, and professional links in a web-based resume format.

## 🌐 About the Project

This website is designed as an online version of my resume. It uses a minimal layout with a bordered resume container, section headings, typography, colors, and basic HTML formatting to create a professional presentation.

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 📌 Sections Included

* **Personal Information**
* **Skills**
* **Education**
* **Experience**
* **Across The Internet**

  * LinkedIn
  * GitHub

## ✨ Features

* Simple and professional resume layout
* Clean HTML structure
* Custom CSS styling
* Responsive viewport configuration
* Styled headings and sections
* Direct links to LinkedIn and GitHub
* No external libraries or dependencies required

## 🚀 How to Run

You don't need to install anything to run this project.

1. Clone the repository:

```bash
git clone https://github.com/bhardwaj577/resume-website.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
